# FritoMusic — Landing Page Oficial 🚀🎵

Landing page web moderna e interactiva para la aplicación Android **FritoMusic**, desarrollada con **React 19**, **TypeScript** y **Vite**.

Diseñada con una estética *Cosmic Audio*, efectos de glassmorphism, partículas interactivas HTML5 Canvas, deck de audio virtual con visualizador espectral reactivo y una vitrina móvil interactiva de 7 vistas impulsada por desplazamiento táctil y de ratón (Scroll-Driven Pinning).

---

## ✨ Características Principales

* **Fondo Cósmico Dinámico:** Canvas interactivo con 165 partículas atraídas por el cursor y ondas de choque acústicas.
* **Deck de Audio Interactivo:** Disco de vinilo giratorio con visualizador de 24 barras de frecuencia reactivas y reproductor conceptual.
* **Vitrina Móvil Dinámica (7 Vistas de la App):**
  1. `01 · Inicio & Biblioteca Local`
  2. `02 · Explorador de Streaming en la Nube`
  3. `03 · Perfil y Discografía de Artistas`
  4. `04 · Gestor de Descargas Masivas e Individuales`
  5. `05 · Frito Recap (Estadísticas de Escucha)`
  6. `06 · Ajustes de Crossfade & Transición Continua`
  7. `07 · Migrador Universal de Listas de Reproducción`
* **Navegación Móvil y de Escritorio:** Cambio dinámico de pantallas mediante desplazamiento vertical (scroll-driven pinning) y gestos táctiles (swipe).
* **Modal de Pantalla Completa (Lightbox):** Inspección en alta definición de cada captura de la interfaz de usuario.
* **Terminal de Descarga Directa:** Enlace al archivo APK oficial (`fritomusic-v1.0.apk`), especificaciones técnicas y verificación de suma SHA-256.
* **Diseño Totalmente Responsivo:** Calibrado para smartphones, tablets y pantallas de escritorio 4K.

---

## 🛠️ Tecnologías

* **Framework:** React 19 + TypeScript
* **Herramienta de compilación:** Vite
* **Estilos:** Vanilla CSS con variables de diseño, glassmorphism y paletas cromáticas Oklch
* **Animaciones:** Canvas 2D API nativa, CSS keyframes acelerados por GPU y Web APIs modernas

## 🚀 Instalación y Desarrollo Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/kurtcobain2728/FritomusicLanding.git
   cd FritomusicLanding
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Compila para producción:
   ```bash
   npm run build
   ```
